# CALORIS — AI-Ready Sound Engine

A fully featured music generator and composition environment, designed for use with AI and for use on mobile platforms.

CALORIS treats a composition as structured, inspectable data: a patch any mind — human or otherwise — can read, write, and revise. Silence is a compositional element, not an absence. Built as a single self-contained HTML file: no install, no account, no internet. Open `index.html` and compose.

Current build: v19.0 (`index.html`). The earlier `CALORIS_V4.html` remains in the repo for history.

Play with it on itch.io: https://katabatic-vector.itch.io/caloris

Part of the **Telos** toolchain by Katabatic Vector, a one-person studio developing entirely on Android.
